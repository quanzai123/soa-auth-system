💡 Hướng dẫn mở xem trực tiếp trên DBeaver:
Nếu trên DBeaver bạn chưa thấy bảng users, nguyên nhân là vì DBeaver đang mở mặc định vào database master (chứ chưa vào google_login_db).
👉 Cách xem nhanh: Trong DBeaver, hãy mở rộng mục: localhost → Databases → google_login_db → Schemas → dbo → Tables → Bấm chuột phải vào users → Chọn View Data (hoặc nhấn F5 để Refresh).
👉 Hoặc mở một tab SQL Editor mới và chạy: USE google_login_db; SELECT * FROM users;
