Xác thực Quyền Truy cập

Khu vực bảo mật được khóa bằng Spring Security Stateless (JWT). Bạn phải đăng nhập để được cấp quyền và giải mã tài nguyên.

Xác thực Chuẩn Google OAuth 2.0 (RFC 6749)
Tài khoản Sinh viên các Trường: Đăng nhập bằng email trường kết thúc bằng .edu.vn (TDTU, Bách Khoa, CNTT, KHTN, Kinh Tế...) hoặc .edu → Tự động cấp quyền STUDENT.
Tài khoản Cá nhân: Đăng nhập bằng Gmail cá nhân (@gmail.com...) → Tự động cấp quyền PERSONAL.
Bảo mật cấp cao: Hệ thống chỉ chấp nhận Token được ký điện tử bởi Google Identity Provider. Đã vô hiệu hóa mọi hình thức gõ email trực tiếp để phòng chống tấn công mạo danh (Authentication Bypass).

Kiểm Thử Các API Hệ Thống

Gọi trực tiếp các endpoint để kiểm chứng cơ chế cấp quyền và phòng vệ.

4 API Cốt lõi
GET (PRIVATE) 200 OK
/api/users/me

Gửi kèm Bearer Token. Server giải mã JWT và đọc hồ sơ từ SQL Server.

GET (PRIVATE) 403 FORBIDDEN
/api/users/me

Không gửi Token. Chứng minh Spring Security chặn đứng ngay tại cổng.

GET (PUBLIC) 200 OK
/api/auth/google/url

API công khai sinh URL ủy quyền Google OAuth 2.0 chuẩn RFC 6749.

POST (PUBLIC) 200 OK
/api/auth/refresh-token

Đổi Refresh Token lấy Access Token mới mà không cần đăng nhập lại.
